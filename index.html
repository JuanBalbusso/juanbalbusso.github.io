01 / Process Automation · Producto propio · En producción
Factory Expense Tracking Automation
Descripción del proyecto

Portal de costos en producción, usado a diario por dos empresas industriales, que permite consultar y comparar costos mensuales en tiempo real sin tocar planillas manualmente. Va más allá de un dashboard básico implementando un cierre de mes que reconstruye los totales reales desde el registro de movimientos (no desde valores "en vivo" que pueden estar desactualizados), detección automática de ítems que necesitan carga manual, y trazabilidad completa de anulaciones. Construido y estabilizado contra datos reales de producción, con 28 tests automatizados que atraparon y previenen 3 bugs concretos que ya habían afectado los números reales del cliente.

Puntos clave
  • Cierre de mes por reconstrucción — soluciona el problema de que la planilla "en vivo" muestre el mes equivocado si el cierre se hace unos días tarde
  • Detección de ítems manuales — identifica qué categorías (sueldos, honorarios) no están conectadas a un formulario y necesitan carga a mano ese mes
  • Anulación con trazabilidad — un movimiento cargado por error se anula sin borrar el registro, manteniendo auditoría completa
  • Suite de 28 tests automatizados que expusieron y previenen bugs reales de producción (coerción de fechas, detección de filas erróneas, cargas duplicadas)
Stack: Node.js, Google Cloud Functions, Google Sheets API, Google Apps Script, HTML/CSS/JavaScript

03 / LLM Engineering · RAG System
InsureLLM — RAG System
Descripción del proyecto

Sistema RAG de producción que permite consultar una base de conocimiento privada de seguros en lenguaje natural. Va más allá de un pipeline básico implementando tres mejoras clave: query expansion con conocimiento del dominio, detección holística de preguntas amplias, y un loop de autoevaluación con LLM-as-judge. Evaluado con 150 preguntas de prueba usando métricas MRR, nDCG y scoring automático.

Puntos clave
  • Query expansion con conocimiento del dominio — resuelve el problema de acrónimos mal interpretados por el LLM
  • Detección holística — identifica preguntas amplias y asegura que todos los documentos fuente estén representados
  • Loop de autoevaluación — un LLM judge puntúa cada respuesta del 1 al 5 y reintenta con feedback si la calidad es insuficiente
  • Evaluación rigurosa con 150 preguntas curadas usando MRR, nDCG y LLM-as-judge answer scoring
  • Stack: Python, OpenAI, ChromaDB, LiteLLM, Pydantic, Gradio, uv

04 / LLM Engineering · Producto propio · En producción
JB AI Agent — Bot de Calificación de Leads por WhatsApp
Descripción del proyecto

Sistema de producción (no un proyecto de curso) que atiende WhatsApp de JB AI Solutions 24/7: responde consultas usando RAG sobre una base de conocimiento propia, detecta el tipo de proyecto (chatbot/agente, Data Science, oferta laboral) y guía la conversación con un checklist específico hasta calificar el lead. Cuando confirma datos de contacto, arma y envía un resumen estructurado automáticamente, además de guardar cada conversación en Postgres para seguimiento.

Construí también un panel de administración propio (no uso ninguna herramienta de terceros) con diseño tipo WhatsApp Web/CRM: lista de conversaciones en vivo vía Server-Sent Events, respuesta manual, difusión de mensajes, favoritos, búsqueda y agenda de contactos.

Puntos clave
  • Backend en FastAPI + PostgreSQL, integrado con la API de WhatsApp Business (Twilio)
  • RAG con ChromaDB sobre base de conocimiento propia para respuestas grounded, no alucinadas
  • Extracción de estado estructurado por turno (Pydantic + structured outputs) para trackear el checklist sin perder el hilo en conversaciones largas
  • Manejo de audio (Whisper), imágenes y PDFs — el bot entiende lo que el cliente le mande
  • Resolví el desafío específico de WhatsApp Business API: mensajes iniciados por el negocio requieren Message Templates aprobados por Meta para esquivar la ventana de 24hs — diseñé el sistema para que esto no dependa de que el cliente escriba primero
  • Prompt engineering iterativo con testing adversarial real: guardrails contra jailbreaks progresivos y fuga de instrucciones internas, validados con conversaciones reales de prueba
  • Panel de administración propio con actualizaciones en tiempo real (SSE), sin depender de refrescos manuales
Stack: Python, FastAPI, OpenAI API, Twilio, PostgreSQL, ChromaDB, Pydantic, Server-Sent Events, HTML/CSS/JS vanilla
